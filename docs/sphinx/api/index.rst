API Reference
=============

Generated from the public headers under ``include/tanh/`` with Doxygen and
Breathe. Every symbol lives in namespace ``thl``. State, the dispatcher and the audio
device manager sit directly in ``thl``; the containers and threading utilities
in ``thl::core``; the processors in ``thl::dsp`` and its nested namespaces
(``fx``, ``filter``, ``granular``, ``resonator``, ``synth``, ``utils``, ...);
the modulation matrix and sources in ``thl::modulation``; the HTTP client and
asset store in ``thl::net``.
